# Vohu

A lightweight and extensible AI agent runtime for building tool-using agents in Go.

> **From thought to action.**

## Status

🚧 Work in progress

Vohu is currently under active development.

## Overview

Vohu aims to provide a simple and extensible runtime for building AI agents that can reason, interact with tools, and perform actions.

The project is designed with simplicity and extensibility in mind, allowing capabilities such as tools, model providers, authorization, and execution management to evolve over time.

## Features

- [ ] Agent runtime
- [ ] Tool calling
- [ ] Conversation management
- [ ] Model providers
- [ ] Tool execution
- [ ] Authorization
- [ ] Persistent history
